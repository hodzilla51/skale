# 2010 — Judicial Examination / Public Law (Constitution component)

Status: **source packet collected / prospective test contaminated / TRAIN analysis permitted**

Dataset role: `TRAIN`

This packet records the source locations used for the 2010 (平成22年) constitutional-law essay extraction.

## Primary official sources

Ministry of Justice — 2010 new judicial examination implementation page:

https://www.moj.go.jp/jinji/shihoushiken/shiken_shinshihou_h22jisshi.html

The page provides the 2010 examination materials, including the essay questions.

Ministry of Justice — 2010 examination results page:

https://www.moj.go.jp/jinji/shihoushiken/jinji08_00010.html

The page lists:

- 論文式試験出題の趣旨 — PDF, 279 KB
- 採点実感等に関する意見 — PDF, 347 KB

These Ministry of Justice pages are the source of record.

## Access / contamination note

The 2010 Phase A model was frozen before problem inspection in `FROZEN_MODEL.md`. During the attempted Phase B retrieval, a search result exposed teacher-signal text together with the problem before a prediction artifact was committed. The prospective test was therefore invalidated and recorded in `CONTAMINATION.md`.

Because 2010 is in `TRAIN`, it remains admissible for ordinary year extraction, teacher-guided fitting, compression accounting, and model construction. It must not be counted as clean frozen-model generalization evidence.
